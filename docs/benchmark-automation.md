# Сбор данных и генерация HTML

Числа не переносятся в HTML вручную. Адаптер получает опубликованные данные, сохраняет исходный снимок и обновляет JSON. React строит из данных общую таблицу, выбор столбцов, диапазоны, сортировку, детали запусков и рейтинг.

## Команды

```sh
# Получить один источник, выполнить полные проверки и собрать сайт с HTML-файлом
npm run refresh:benchmarks -- --source terminal-bench

# Обновить все подключённые источники, проверить и собрать
npm run refresh:benchmarks

# Собрать из сохранённых данных без обращения к источникам
npm run export:html
```

Любая успешная `npm run build` создаёт обычный сайт и `dist/vibe-atlas.html`. В автономном файле встроены JavaScript, стили, шрифты и JSON для скачивания. Фильтры и сортировка работают при открытии файла без сервера и сети. Внешние ссылки на первоисточники требуют сети.

`refresh:benchmarks` запускает адаптеры из `data/import-jobs.json` последовательно и прекращает работу при первой ошибке. Затем выполняет `npm run check`, включая сборку. Обновление нескольких источников не является общей транзакцией: ранее успешно обновлённый источник остаётся обновлённым при ошибке следующего. Команда не публикует сайт. Расписание автоматического сбора пока не настроено.

## Подключение бенчмарка

Новые источники записывают пакеты в `data/benchmark-packs.json`. Один пакет содержит источник и дату проверки, версию парсера, путь и SHA-256 снимка, определения столбцов, паспорта и все запуски. `src/data/benchmark-pack-schema.ts` задаёт общий контракт.

Для нового источника нужны:

1. Адаптер его формата и проверка соответствия опубликованным данным. При исчезновении результатов, полей или смене версии адаптер останавливает обновление для разбора причины.
2. Определения метрик, единицы, условия и паспорт с пятью отдельными оценками: независимость, утечка, насыщение, воспроизводимость и сопоставимость.
3. Явные соответствия исходных названий редакционным моделям. Запуск без соответствия сохраняется в пакете, но не присваивается похожей модели.
4. Задание в `data/import-jobs.json` и проверка преобразования исходного снимка в `scripts/validate-data.ts`.

После этого интерфейс получает столбцы, паспорта, результаты, сортировку и награды из пакета. Добавлять источник в JSX или вручную формировать строки HTML не требуется. Новые столбцы доступны в выборе бенчмарков; исходные четыре остаются выбранными по умолчанию.

Условия и соответствия моделей остаются редакционной работой. Автоматизация переноса чисел не подтверждает независимо методологию, актуальность модели или отсутствие утечки.

Исследовательские агенты находят материалы и передают их по [общему регламенту](research-workflow.md). Приоритет имеют результаты и условия, опубликованные стоимость и время собираются при наличии. Недостающие токены отдельно не ищутся, полученная телеметрия сохраняется. Папки передачи не читаются сборкой автоматически. [Агрегация исследования](research-aggregation.md) объединяет проверенные передачи и подключает новые пакеты из сохранённых наблюдений. Машинный каталог медиа, опросов и идентичности реализован, его просмотр в интерфейсе ещё предстоит.

## Масштабирование

Сейчас ограничено число отображаемых строк и столбцов, а подробности открываются по клику. Все подключённые данные входят в сборку: это ограничение DOM, а не загрузка JSON по сети. Автономный HTML тоже содержит полный набор и будет расти вместе с ним.

Следующий этап при росте набора — отдельные пакеты данных с загрузкой по выбору источника и виртуализация длинной таблицы. Для автономного экспорта потребуется отдельная сборка с вложенными пакетами. Экспортёр сейчас проверяет, что Vite создаёт один JavaScript entry и один stylesheet; изменение разбиения на chunks потребует обновления экспорта.
