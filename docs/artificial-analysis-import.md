# Первый импорт Artificial Analysis

Источник: [Coding Agents](https://artificialanalysis.ai/agents/coding-agents). Проверено 10 октября 2026. В снимке 37 конфигураций и 111 результатов трёх тестов. Составной Coding Agent Index v1.5 сохранён отдельно от результатов компонентов.

## Что собрано

Полная таблица передаётся в данных React Flight. Некоторые строки ссылаются на объекты из блока выделенных участников; адаптер разрешает эти ссылки. Первоначально видимые строки страницы не определяют полноту импорта.

Сохраняются все строки источника, точные названия и конфигурации, исходные идентификаторы, результаты компонентов, веса, версии агентов, средние показатели, суммы, перцентили, отказы и аудит reward hacking. Дополнительные поля сохраняются. Идентификатор `hostModelSlug` принадлежит источнику; это не подтверждённый API ID модели.

Текущий адаптер охватывает страницу Coding Agents. Общий каталог моделей AA подключён [отдельным адаптером](aa-models-import.md). Остальные разделы AA ещё не подключены. Снимок содержит предыдущие поколения и недоступные модели. Их наличие не подтверждает актуальность модели и не добавляет её в основной набор проекта. Следующий этап: проверенное сопоставление линеек и вариантов по [правилам охвата](model-scope.md).

## Обновление

Из корня проекта:

```sh
npm run import:artificial-analysis
npm run check
```

Для повторного разбора уже полученного HTML нужна исходная дата успешной проверки. Повторный разбор не делает данные свежее:

```sh
npm run import:artificial-analysis -- --stdin --checked-at 2026-10-10T14:53:23.000Z < .cache/artificial-analysis/current.html
```

При известной дате получения можно добавить `--retrieved-at` с ISO timestamp. Нераскрытая дата публикации и неизвестная дата получения не выдумываются. Полный HTML находится в игнорируемой `.cache/`; в публичные файлы попадают данные таблицы.

- `data/artificial-analysis.json`: текущие результаты и происхождение.
- `data/snapshots/artificial-analysis/current.json`: исходные строки текущей таблицы.
- `data/snapshots/artificial-analysis/history.json`: предыдущие успешные наборы, появляется при обновлении.
- `data/benchmark-definitions.json`: паспорта версий и редакционный разбор.

Происхождение содержит URL, дату проверки, известную дату получения, SHA-256 HTML и исходных строк, версию парсера и индекса. Проверка данных сверяет снимок с опубликованными строками и их контрольной суммой. История хранит значения предыдущих наборов; полный HTML старых загрузок пока отдельно не архивируется.

## Защита от неполного обновления

До записи проверяются схема, уникальность конфигураций, число компонентов, их веса и соответствие индексу. Изменение версии индекса, потеря строк, тестов, средних метрик или перцентилей останавливают обновление. Предыдущий успешный набор сохраняется при отклонении входных данных. Сетевые ошибки также не обновляют дату проверки.

Обнаруженное исчезновение может быть законным изменением источника. Для такого случая нужен разбор причины и обновление адаптера; автоматического обхода проверки нет. Запись отдельных файлов использует временный файл для текущего каталога. Общей транзакции файловой системы пока нет: после прерывания записи `npm run check` должен пройти перед публикацией.

CLI-проверка использует синтетическую страницу с разделёнными Flight-данными и ссылками между строками. Проверяет сохранение всех конфигураций, неизвестных полей и метрик; при потере данных, неверном индексе, битой ссылке или смене версии сравнивает предыдущие файлы побайтно.

## Отображение и доверие

Сайт показывает измерения выбранных версий в [общей таблице моделей](model-comparison.md): бенчмарки выбираются в столбцах, конфигурации раскрываются внутри ячеек, доступны диапазоны, сортировка и медали. Все исходные конфигурации сохранены в скачиваемом JSON; наличие старого поколения в снимке не добавляет его в основной каталог. В паспортах различаются автор теста и исполнитель замера. У каждого источника и разбора указана дата проверки.

Методология прочитана по [описанию AA](https://artificialanalysis.ai/methodology/coding-agents-benchmarking), проверенному 10 октября 2026. Независимость финансирования, воспроизводимость, насыщение и попадание заданий в обучение не считаются подтверждёнными. Статусы разбора не являются оценкой качества модели. Цена API не описывает лимиты подписок. Более подробная структура находится в [методологии проекта](benchmark-methodology.md).
