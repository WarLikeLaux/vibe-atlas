# Импорт бенчмарков Cursor

Проверено 10 октября 2026. Это публикации вендора. Измерения Cursor, перепечатанные заявления других вендоров и отдельные версии тестов сохраняются раздельно.

## Охват

- [CursorBench 4.0](https://cursor.com/evals): 68 конфигураций, 16 названий моделей, все опубликованные effort, баллы, стоимость задачи, выходные токены и средние шаги. Сохранены и конфигурации, которые график скрывает по умолчанию.
- [Страница Composer](https://cursor.com/composer): 14 баллов в Terminal-Bench 2.0, SWE-bench Multilingual и CursorBench 3.1. В ячейках Opus и GPT для CursorBench опубликовано по два effort; оба сохранены.
- [Описание CursorBench](https://cursor.com/blog/cursorbench) и [SWE-bench Multilingual](https://www.swebench.com/multilingual.html) используются для первоначальных паспортов, а не как подтверждение полного протокола конкретного запуска.

Это полный импорт двух перечисленных таблиц, а не всех исследований Cursor. Графики в статьях о тренировке и исторические таблицы технического отчёта Composer 2 пока не разобраны. Изучена [публикация Composer 2.5](https://cursor.com/blog/composer-2-5), опубликованная 18 мая 2026; её график результатов повторяет таблицу Composer и не считается независимым замером.

## Разбор источника

CursorBench отдаёт видимую таблицу в HTML, а точные данные графика находятся в подключённом JavaScript. Таблица округляет средние шаги: 184,5 превращается в 185; в исходных данных встречается и точность 63,46. Импорт сохраняет исходные значения.

`scripts/cursor-source.ts` использует TypeScript AST только для чтения массива литеральных данных. Код сайта не выполняется. Строки, числа, логические значения, массивы и объекты сохраняются; вычисления, вызовы и другие исполняемые выражения внутри данных отклоняются. Дополнительные поля сохраняются в исходном снимке.

Названия, баллы, стоимость и токены сверяются с каждой строкой HTML; шаги сравниваются с округлением источника. Успешный импорт требует совпадения всех конфигураций. Версия берётся из заголовка CursorBench 4.0: название константы в текущем JavaScript по-прежнему содержит `31` и не подтверждает версию теста. Одинаковые таблицы для desktop и mobile на странице Composer дедуплицируются; различающиеся копии останавливают импорт.

## Файлы и обновление

- `data/cursor-benchmarks.json`: 82 результата, происхождение и контрольные суммы HTML и JavaScript.
- `data/cursor-passports.json`: четыре отдельных паспорта с первоначальным разбором и неизвестными условиями.
- `data/snapshots/cursor/current.json`: полные семьи, модели, конфигурации графика и текстовые ячейки обеих таблиц.
- `data/snapshots/cursor/history.json`: предыдущие успешные результаты вместе с исходными структурированными снимками.
- `.cache/cursor/current.json`: последний полученный HTML и JavaScript; кеш исключён из Git.

```sh
npm run import:cursor
npm run check
```

Для офлайн-разбора передай JSON в stdin:

```sh
npm run import:cursor -- --stdin --checked-at 2026-10-10T16:00:00.000Z < cursor-input.json
```

Поля входа: `leaderboardHtml`, `leaderboardScript`, `leaderboardScriptUrl`, `composerHtml`, необязательный `retrievedAt`. Дата команды является примером; у реального снимка укажи время проверки. При отсутствии подтверждённого времени получения оно остаётся неизвестным. Дата публикации изменяемых таблиц тоже неизвестна; дата обновления цены в changelog не подменяет её.

Смена версии, исчезновение конфигурации или исходного поля, несовпадение HTML и JavaScript, неподдерживаемый формат и старый снимок останавливают обновление до записи результатов. История сохраняет предыдущий успешный набор. Проверка реального CLI защищает точность, неизвестные значения, effort, атрибуцию перепубликации и сохранность набора после ошибки. Записи заменяются по файлам; общей транзакции нескольких файлов пока нет. После прерывания записи обязательна полная проверка перед публикацией.

## Интерпретация

Cursor является автором и исполнителем CursorBench, а также разработчиком Composer. Эти роли видны читателю. Публичные баллы Opus 4.7 и GPT-5.5 на странице Composer отмечены самим Cursor как self-reported: это перепубликации, а не независимые замеры Cursor. Прямые первоисточники этих конкретных запусков ещё не проверены.

CursorBench 4.0 и 3.1 имеют разные распределения задач. Composer 2.5 получает 27,7% в 4.0 и 63,2% в 3.1; это два отдельных результата, не падение на неизменном тесте. Сведения о 3.1 из методологической статьи не подменяют текущую версию 4.0 на странице результатов.

Стоимость задачи рассчитывает Cursor по опубликованным ценам входных, кешированных и выходных токенов. Это не цена подписки и не квота. Поле `outputTokens` обозначает выходные токены; его агрегация, токенизатор и отдельные reasoning-токены не раскрыты. `avgSteps` обозначает средние шаги. У Terminal-Bench и SWE-bench в этой таблице нет телеметрии: отсутствие не превращается в ноль.

Авторы [Terminal-Bench 2.1](https://www.tbench.ai/news/terminal-bench-2-1), проверено 10 октября 2026, сообщают об исправлении 28 из 89 задач версии 2.0: проблемы зависимостей, ресурсов и несоответствия условий тестовым проверкам. В паспорте сохранено это ограничение. Размер датасета 2.0 подтверждён [статьёй, версия 1](https://arxiv.org/abs/2601.11868v1); 89 не считается автоматически числом оценённых задач публикации Cursor.

Для SWE-bench Multilingual известен описанный авторами датасет из 300 задач, но размер оценённой выборки и ревизия запусков Cursor неизвестны. У всех новых замеров не раскрыты число попыток, версия агента, бюджеты, конкретный judge и неопределённость. Независимый аудит утечек, насыщения и воспроизводимости ещё не выполнен. Небольшие разницы не следует автоматически объявлять значимыми.

Названия и ключи моделей в данных графика принадлежат Cursor и не считаются подтверждёнными официальными API ID. Тег `Latest` не определяет актуальность линейки в каталоге Vibe Atlas. В снимке нет GPT-6.1, MiniMax M3.1 Flash Preview или Muse Spark Contributor; результаты прежних поколений и обычных вариантов не переносятся на них. Исходные сравнения сохраняются по [правилам охвата](model-scope.md).

## Интерфейс

Результаты находятся в [общей таблице моделей](model-comparison.md) вместе с AA. Бенчмарки и протоколы представлены отдельными выбираемыми столбцами. Effort раскрываются внутри ячейки с диапазоном, точной конфигурацией и телеметрией. Предыдущие поколения из сравнения Composer не добавляются в основной каталог и не передают оценки своим преемникам.

CursorBench 3.1 доступен для изучения, но не добавляет медаль поверх текущего 4.0. Если в редакционном охвате осталась одна измеренная модель публичного теста, награда не выдаётся. Все 82 исходных результата сохранены в JSON. Данные пока входят в статическую сборку; ограничение строк не является загрузкой по сети. Для просмотра изменений предоставляется автономный HTML с работающими фильтрами и экспортом JSON.
