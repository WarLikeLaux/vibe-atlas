# Агрегация первой партии исследований

11 октября 2026 результаты шести исследовательских заданий объединены с сохранением исходных карточек. Сверка первоисточников выполнена отдельно для бенчмарков, медиа, арен и идентификаторов. Область проверки и оставшиеся вопросы записаны в отчётах, отсутствие сведений не считается подтверждением.

## Что доступно

| Данные               | Результат                                                                             | Где смотреть                                     |
| -------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Новые числовые тесты | 4 пакета, 14 столбцов, 638 исходных строк и результатов, 83 сопоставленных результата | Общая таблица и `data/benchmark-packs.json`      |
| Медиа                | 63 записи: 33 мнения, 6 замеров, 24 кандидата и материала контекста                   | `data/research-catalog.json`, набор `media`      |
| Опросы               | 4 карточки: 1 проверенный опрос использования, 3 неподтверждённых кандидата           | `data/research-catalog.json`, набор `polls`      |
| Модели               | 45 записей идентичности, источников, конфликтов и неизвестных полей                   | `data/research-catalog.json`, набор `identities` |

Всего в машинном каталоге исследования 112 записей. В общей таблице теперь 47 столбцов и 1259 сопоставленных результатов для существующих 35 редакционных позиций. Актуальность всех позиций полностью не переаудирована. Исторические строки без точного соответствия сохранены в пакетах, но не добавляют моделей каталога. Мнения и обычные опросы не влияют на медали. Их просмотр в интерфейсе ещё не реализован.

## Подключённые измерения

- Arena: WebDev, Text Coding и Image-to-WebDev, 615 исходных строк, 65 сопоставленных запусков для 24 моделей. Баллы предпочтений остаются баллами, не процентами решённых задач. Fullstack сохранён как архив пересекающегося поднабора, без дополнительного столбца и медали.
- SWE-Bench Pro V2 HARD-51: 12 исходных запусков, три агентских протокола, семь точных соответствий. Полный набор, Private и исследование harness пока не подключены. Для Haiku 5.5 повторно подтверждена погрешность ±13.01 процентных пункта, прежнее нулевое поле сохранено отдельно как исходное расхождение.
- ProgramBench: две effort-конфигурации обычной Muse Spark 1.3, три метрики и шесть результатов. Contributor не получает эти результаты. В подключённом охвате одна модель, награды отключены.
- SlopCodeBench: GLM-5.3 с pi 0.84.2 и xhigh, пять отдельных метрик, награды отключены. Поднаборы пересекаются, пять чисел не создают пять независимых экспериментов.

Снимки, паспорта, числовые поля и соответствия восстановимы из исходных наблюдений и редакционных определений. `scripts/validate-data.ts` проверяет контрольные суммы и преобразование каждого пакета. ProgramBench и SlopCode сохраняют опубликованные расходы и телеметрию, их единицы и область расчёта указаны в данных.

## Команды

```sh
# Объединить нормализованные карточки и их полные поля
npm run aggregate:research

# Восстановить проверенные пакеты из сохранённых наблюдений и receipts
npm run import:research

# Проверить данные и собрать сайт с автономным HTML
npm run check
```

`data/research-jobs.json` задаёт источники нормализованных карточек. Агрегатор сохраняет поля, статусы, происхождение и неизвестные значения. Некорректный, неполный или потерявший идентификаторы набор не заменяет предыдущий каталог. Исчезнувшие карточки одной партии требуют разбора. Повторная агрегация не превращает `needs-context` в подтверждённое мнение.

`data/research-benchmarks.json` задаёт проверенные пакеты, их снимки, редакционные определения, receipts и источники. `import:research` выполняет преобразование сохранённой партии, сетевые запросы не делает и даты проверки не обновляет. Новые данные требуют новой сверки и обновления входов. Четыре прежних сетевых адаптера из `data/import-jobs.json` продолжают работать отдельно. Сбор по расписанию и публикация не включены.

## Ограничения и происхождение

Все 12 карточек X остаются `needs-context`, успешно проверенных оригиналов в исходной партии нет. Даты зеркал и пересказы не выдаются за оригинальную речь авторов. У MiniMax-примера AYi ссылка на шапку Thread Reader отвергнута, потому что нужный текст расположен в `More from` другого материала. У MiniMax-AI.chat остаётся конфликт дат публикации и измерения.

Медиа сохраняют 32 состояния `source-verified`, 18 `needs-context`, 11 `candidate` и две связи `duplicate`. Это состояния прочтения источников, не доказательство качества моделей или независимости авторов. Новая успешная сверка 13 карточек по десяти оригинальным страницам хранится отдельно от первоначальных дат. Несколько комментариев одного треда остаются разными высказываниями. Reddit crossposts не создают новых независимых авторов.

Stack Overflow хранит все 33 варианта Used и знаменатель 12255. Это добровольный многовариантный опрос использования агентов, не голосование за единственную лучшую модель. X, Reddit и ZDNET опросы остаются кандидатами без принятых числовых строк.

GPT-6 Luna не заменяет запрошенную GPT-6.1 Luna. MiniMax M3 отделена от Flash Preview, Muse Spark 1.3 от Contributor, rolling Qwen от датированного API snapshot. Исследовательские соответствия модели в мнениях сохраняются как кандидаты, неподтверждённые API ID не назначаются. Записи идентичности сохраняют область повторной проверки, полная сверка всех дат релиза и планов доступа не заявляется.
