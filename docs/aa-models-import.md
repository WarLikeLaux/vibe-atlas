# Импорт раздела моделей Artificial Analysis

Источник: [AA Models](https://artificialanalysis.ai/leaderboards/models), проверен 10 октября 2026. Сохранены 697 конфигураций: 267 источник не помечает архивными, 430 помечает архивными. Статус AA не подтверждает последнюю версию конкретной линейки.

## Полнота и условия

Из встроенных данных страницы получена полная таблица, включая скрытые столбцы. Коллекция с результатами отличается от краткого списка моделей навигации. Адаптер сохраняет все опубликованные поля, точные названия и исходные slug, признаки reasoning, оценённого индекса и архивного статуса.

В снимке встречаются 39 числовых полей. Есть результаты бенчмарков, компоненты оценок, контекст, цены API, скорость, задержки и перцентили. Поля с отрицательными баллами сохраняют знак, нулевой результат не превращается в отсутствие данных. Некоторые значения отсутствуют структурно, другие равны `null`; исходное различие сохраняется. Пропуски не дополняются нулями.

Имена и единицы метрик описаны в `data/model-metrics.json`. Версии замеров, которые эта таблица не раскрывает, остаются неизвестными. Методология [Intelligence Index v4.3.2](https://artificialanalysis.ai/methodology/intelligence-benchmarking) прочитана 10 октября 2026; это дата проверки описания, а не подтверждение версии каждого исторического замера. Полный паспорт каждого теста, авторство и редакционный аудит ещё предстоят.

Результаты моделей и готовых coding agents находятся в разных разделах. Даже у одноимённых тестов условия могут различаться: например, раздел моделей AA использует mini-swe-agent для Terminal-Bench 4.0. Точный harness и его версия по каждой строке общего leaderboard не раскрыты. Нельзя объединять эти замеры по совпадению названия теста или модели.

Есть результаты GLM-5.3-Flash и MiniMax-M3. Они не заменяют GLM-5.3 или MiniMax-M3.1-Flash-Preview. Подтверждённое сопоставление актуальных линеек, вариантов и официальных API ID остаётся отдельной задачей по [правилам охвата](model-scope.md).

## Обновление

Из корня проекта:

```sh
npm run import:aa-models
npm run check
```

Повторный разбор локального снимка сохраняет исходную дату проверки:

```sh
npm run import:aa-models -- --stdin --checked-at 2026-10-10T15:43:08.000Z < .cache/aa-models/current.html
```

- `data/aa-models.json`: текущий набор и происхождение.
- `data/snapshots/aa-models/current.json`: исходные строки таблицы.
- `data/snapshots/aa-models/history.json`: предыдущие успешные наборы, появляется при обновлении.
- `.cache/aa-models/current.html`: полный HTML, исключён из Git.
- `scripts/react-flight.ts`: общий декодер данных страницы для двух адаптеров.

Схема и шкалы проверяются до записи. Потеря конфигурации или опубликованного поля, некорректная доля, повтор slug и попытка заменить новый снимок старым останавливают импорт. Контрольные суммы и совпадение исходных строк с публичным набором проверяются перед сборкой. Общая транзакция нескольких файлов пока не реализована; после прерывания записи обязательна полная проверка перед публикацией.

## Рост интерфейса

Все источники представлены в [общей таблице моделей](model-comparison.md). Явный редакционный каталог определяет строки; флаг `deprecated: false` сам по себе не подтверждает последнюю версию линейки. Предыдущие поколения остаются в полном JSON и не заполняют оценки новых версий.

Пользователь выбирает столбцы, сортирует по любой метрике и раскрывает конфигурации внутри ячейки. Показ ограничен десятью строками с добавлением следующих. Диапазон описывает минимум–максимум опубликованных конфигураций одного протокола. Данные пока входят в статическую сборку; это ограничение отрисовки, а не загрузка по сети.

Составные индексы доступны для сортировки, но не добавляют награды поверх компонентов. Условия и телеметрия сохраняют исходные единицы. Полнота хранения не зависит от ограничений показа. Для просмотра изменений предоставляется автономный HTML-файл с работающим интерфейсом.
