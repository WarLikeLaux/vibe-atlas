# Сверка бенчмарков первой партии

Сверка выполнена 11 октября 2026. Точная метка проверки находится в [manifest.json](manifest.json). Общие данные сайта этим исполнителем не изменялись. Здесь находятся три пакета для интегратора, редакционные определения отдельно от исходных наблюдений и квитанции соответствия каждого запуска исходному JSON pointer.

Исторические строки HARD без соответствия каталогу остаются в пакете без `modelId`, остальные исходные строки ProgramBench сохраняются в снимке. Muse Spark 1.3 не сопоставляется Contributor. ### SWE-Bench Pro V2 HARD-51

[Первичная таблица](https://labs.scale.com/leaderboard/swe_bench_pro_public_v2) повторно прочитана через web. Семь текущих соответствий: Fable 5.1, GPT-6 Astra, Kimi K3, GPT-5.6 Terra, GLM-5.3, Gemini 3.8 Flash и Haiku 5.5. Их проценты сохранены без пересчёта. Claude Code, Codex и mini-swe-agent разделены по протоколам.

Обнаружено расхождение неопределённости Haiku 5.5. Сейчас страница показывает `52.94 ± 13.01`, тогда как переданная исследователем запись содержит `confidenceInterval_upper: 0`. В новом наблюдении сохранено показанное 13.01, исходное старое поле также осталось в `earlierSourceFields`. Оно не используется как доказательство нулевой погрешности. Метод и уровень интервала неизвестны.

Прочитан [V2 README](https://raw.githubusercontent.com/scaleapi/SWE-bench_Pro-os/main/v2/README.md). HARD содержит 51 задачу, отобранную по неудачам нескольких семейств. Locked protocol описывает ограничения сети и повторную проверку patch. Выполнение этих условий каждой опубликованной строкой не проверено. Страница также содержит описание прежних лимитов, поэтому сопоставимость помечена `disputed`. В группе Claude Code одна текущая модель, её награды отключены. В остальных двух группах есть несколько текущих моделей. Паспорт прямо указывает ограничения сопоставимости, автоматического доказательства независимости и отсутствия утечки нет.

Полный HTTP-ответ таблицы заново получить не удалось: сервер вернул 403. Поэтому снимок явно назван наблюдениями первичной страницы с отдельно сохранённым прежним извлечением. Все 12 баллов HARD независимо прочитаны в представлении web. Это ограниченная числовая сверка, а не утверждение о полном повторном импорте всех метаданных.

### ProgramBench

Повторно прочитаны [основная страница](https://programbench.com/), [Extended](https://programbench.com/extended/) и run pages [max](https://programbench.com/run/muse-spark-1-3-max/) и [xhigh](https://programbench.com/run/muse-spark-1-3-xhigh/). HTTP-ответ основного URL получен заново, его SHA-256 записан в снимке. Массив `var results` извлечён как JSON. Это числовой источник, без приблизительного чтения графика. Все его поля совпадают с переданным снимком. Таблица также совпадает после нормализации пробелов между inline HTML-тегами.

Resolved и Almost Resolved сохраняются в процентах, Behavioral Test Pass Rate в исходной дробной шкале. Значения Muse max/xhigh разделены. Стоимость API на задачу, вызовы и исходное поле tokens сохранены без самостоятельного расчёта расходов. Состав и знаменатель tokens неизвестны. Оригинальные task rows остаются в папке передачи, их 400 строк не превращаются в дополнительные агрегатные запуски.

У xhigh указаны 199 solutions при 200 instances и одна строка n/a. Правило знаменателя агрегатов не установлено, собственный пересчёт не выполнялся. Точная версия mini-SWE-agent и бюджеты неизвестны. Сайт перечисляет Meta среди авторских организаций, поэтому результат Muse не считается независимым от Meta. В каждом из трёх столбцов только одна текущая точно сопоставленная модель, награды отключены.

### SlopCodeBench

[Aggregate JSON](https://raw.githubusercontent.com/michaelasper/benchmarks/main/data/glm-5.3-pi-xhigh-2026-08-19/result.json) получен заново. SHA-256 ответа `dd306f9cda2f63e6e660037b752a3da5bd9aa1c68e19e9e023cb7d7a070702e2` совпадает с передачей. [README](https://raw.githubusercontent.com/michaelasper/benchmarks/main/data/glm-5.3-pi-xhigh-2026-08-19/README.md) и [отчёт](https://raw.githubusercontent.com/michaelasper/benchmarks/main/glm-5.3-pi-on-slop-code-bench.md) подтверждают точные GLM-5.3, pi 0.84.2, xhigh, just-solve и каталог v1.0 с revision.

Strict, isolated, core checkpoints, полностью решённые проблемы и проблемы хотя бы с одним strict pass являются отдельными метриками. Исходные pct-поля сохранены, новые проценты не вычислялись. Снимок содержит весь aggregate с опубликованными стоимостью, временем, токенами, шагами и распределениями. Категории токенов не складываются.

У запуска есть 14 продолжений после неудачи и 12 evaluations без prior tests. Runner revision и точная dirty-runtime правка неизвестны. Checkpoint records и trajectories не загружены, повтор не выполнялся. Награды отключены: один запуск одной модели. Поднаборы чужих отчётов не добавлены как независимые подтверждения.

## Контракт интеграции

Для каждого источника `*.pack.json` содержит готовый generic pack, `*.definitions.json` содержит редакционные определения и mappings, `*.receipt.json` связывает каждый `runId` с `scorePointer`, source URL, исходной моделью, конфигурацией и точным score. `sourceModelNamePointer`, `configurationPointers` и `telemetryPointers` позволяют отдельно сверить источник названия, раскрытые условия и каждое показанное поле телеметрии. У ProgramBench Resolved/Almost разрешено только снятие знака процента и пробелов из исходной строковой ячейки. Остальные scores являются прямыми числовыми полями снимка.

`snapshotPath` использует целевой путь `data/snapshots/<source>/current.json`. Физические файлы здесь лежат по таким же вложенным относительным путям. Интегратор копирует снимки в общие `data/`, добавляет источники и пакеты, проверяет квитанции и контрольные суммы. Снимки нельзя переформатировать после фиксации SHA-256 без обновления pack, receipt и manifest.

[Генератор кандидатов](build-candidates.py) пишет только в эту папку. Он повторно читает ProgramBench и SlopCode, для HARD использует явно сверенные наблюдения и прежний артефакт. Запуск генератора не заменяет независимую проверку новой версии таблицы. Сайт не читает папку передачи автоматически. Проверки общей интеграции и страницы выполняет основной интегратор.

Проверены `packSchema`, `validatePacks`, контрольные суммы всех трёх снимков, все scores, исходные названия, доступные configuration pointers, каждая единица и значение телеметрии, редакционные mappings и определения. Markdownlint и Prettier для файлов передачи прошли. Общий `npm run check` здесь не запускался: общие файлы не менялись, конечную интеграцию проверяет основной исполнитель.
