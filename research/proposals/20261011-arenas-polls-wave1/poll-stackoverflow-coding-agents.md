# Stack Overflow 2026: использование coding agents

- Идентификатор: poll-stackoverflow-coding-agents.
- Задание: 20261011-arenas-polls-wave1.
- Состояние: source-verified.
- Оригинал: [AI data, AI coding agents](https://survey.stackoverflow.co/2026/ai/data). Методология: [Methodology](https://survey.stackoverflow.co/2026/methodology). Сверены 2026-10-10T18:49:34Z.
- Автор: Stack Exchange Inc. Дата публикации неизвестна. Fielding: 2026-06-23 по 2026-08-05. Начало вне 90-дневного окна, конец внутри. Результат описывает прошлый год, не только последние 90 дней.
- Вопрос, пересказ: какие coding agents/assistants использовали за прошлый год и какие хотите использовать за следующие шесть месяцев? Здесь сохраняется опубликованный сегмент Used.
- Выборка вопроса: n = 12,255. Все 33 опубликованных варианта, counts и проценты сохранены в [poll-stackoverflow-coding-agents.json](poll-stackoverflow-coding-agents.json). Например Claude Code: 8,030 / 65.5%, OpenAI Codex: 3,620 / 29.5%, Cursor: 3,127 / 25.5%.
- Это многовариантное использование инструментов, не слепой тест и не голосование за единственного победителя. Версии моделей неизвестны. Название Open Code сохранено буквально.
- Набор: stackoverflow.com, blog и добровольная email-рассылка. Самоотбор ограничивает обобщение.
- Общая выборка: 39,266 строк, 30,903 valid responses. Не подставлять общую выборку в знаменатель вопроса. Методология допускает substantive-response recovery даже при bot flag. Код отбора не аудирован.
- Интервалы и взвешивание неизвестны. Counts и проценты сохраняются без обратного восстановления людей из округлений.
- Извлечение: extract-v1 из таблицы оригинала. Проверяющая роль: исследователь арен. SHA-256 в [checksums.json](checksums.json).
- Атрибуция: Stack Exchange Inc. (2026), Stack Overflow Developer Survey 2026, ODbL 1.0. Лицензию учесть при интеграции.
- Интеграция: отдельный слой опросов. Баллы моделей и медали из этих данных не создавать. Полный questionnaire, сегмент Want to use и соответствия агента каталогу ещё не сверены.
