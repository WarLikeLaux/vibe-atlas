Выполнена арифметическая сверка извлечения, а не повтор моделей:

- Puter: суммы восьми строк output tokens совпали с опубликованными totals 12 471 и 14 076. Источник и дата в карточке 07. Категории reasoning не складывались с общим выходом.
- MiniMax: сумма per-task assertions совпала с 92/114, calls с 54, сумма опубликованных округлённых цен с 0.053620 USD. Источник и дата в карточке 11. Это не проверка API billing. Post hoc 8 192 diagnostic не заменяет исходный pass@1.
- Contributor: для шести строк выполняется опубликованное равенство cached + uncached = input. Источник и дата в карточке 12. Опубликованные deltas сохранены отдельно, пересчёт по округлённым dollar amounts не подменяет исходные проценты. Reasoning/output не складывались.
- SHA-256 сохранённого SlopCodeBench JSON совпал с provenance. Структура JSON прочитана. Стоимость не пересчитана по современным тарифам.

Внутренняя проверка пакета включает JSON parsing, количества карточек и статусов, существование относительных ссылок, наличие источников и дат, проверку SHA-256 и поиск приватных путей, ключей и незаполненных полей шаблонов. Проверка UI и `npm run check` не запускались: код сайта и опубликованные общие данные не менялись, публикации нет. Перед будущей интеграцией проверки проекта выполняются отдельно.

## Неизвестное и дальнейшая работа

Ни один модельный прогон самостоятельно не повторён. Коммерческая независимость, отсутствие утечек и насыщение широкого coding не доказаны. Нераскрытые effort, routing, даты запуска, версии harness и funding сохранены неизвестными. Исторические цены и измерения не объявлены текущими тарифами или квотами. Статистические intervals не придуманы для single trials.

Для следующей конечной партии полезны проверка YouTube с таймкодом и происхождением транскрипта, получение MiniMax bundle и разрешение дат, чтение fixtures SSHdotCodes, pinned runner и checkpoint metadata SlopCodeBench, сессионные артефакты Contributor и оригиналы дополнительных кандидатов. Эти шаги не выполнены и не обещаны как автоматическое продолжение.

Текущая партия поиска и передачи закончена. Интеграция, общий дедупликат между волнами, подтверждение актуальных официальных идентификаторов и полный охват каталога выполняются отдельно после сверки. Изменения сделаны только в папке этой передачи, без дополнительных агентов, commit, push или публикации.
