# Задание 20261012-subscriptions-wave3

## Результат

- Идентификатор задания: 20261012-subscriptions-wave3.
- Роль: поиск справочных сведений о подписках.
- Цель: читатель Vibe Atlas получает справочник подписок: планы, доступные модели и агенты, опубликованные лимиты в исходных единицах, окна сброса, цены и условия доступа.
- Материалы на выходе: машинный JSON со сведениями и источниками, перечень проверенных страниц, список оставшихся вопросов.
- Папка передачи: `research/proposals/20261012-subscriptions-wave3/`.

## Область поиска

- Модели и линейки: основной набор из `docs/model-scope.md`. Приоритет подписок: Cursor Pro (Grok 4.7, Composer 2.5), ChatGPT/Codex (GPT-6.x), Anthropic Claude, Google AI, Z.AI (GLM-5.3), MiniMax, Meta (Muse Spark).
- Типы сведений: планы подписки, доступные в плане модели и агенты, лимиты (токены, запросы, сообщения, кредиты — в исходных единицах без подмены), окна сброса, общие пулы, региональные условия, цены, даты проверки.
- Источники: только официальные страницы условий и тарифов. Реестр `data/sources.json` ссылками не является проверенным фактом — каждую цифру сверять с оригиналом.
- Период публикаций: текущие условия на октябрь 2026.
- Проверить изменения уже найденных материалов: неприменимо.
- Граница партии: не менее 5 подписок с заполненными сведениями; поиск останавливается при покрытии приоритетного списка или исчерпании области.

## Контекст и правила

Прочитайте `AGENTS.md`, `PRODUCT.md`, `docs/model-scope.md`, `docs/data-policy.md` и `docs/research-workflow.md`.

Каждое сведение хранит источник и дату проверки. Неизвестный лимит остаётся неизвестным, единицы не подменяются. Цена API не является основной осью, но сохраняется при наличии. Секреты, персональные квоты и аккаунты в передачу не включаются.

## Полномочия

- Разрешённые изменения: только файлы в `research/proposals/20261012-subscriptions-wave3/`.
- Разработка адаптера и изменение общих данных: не входит.
- Публикация и push: не входят.
- Параллельные исполнители: задание 20261012-vendor-recommendations-wave3 собирает рекомендации вендоров — область не пересекается, дубликаты на стыке помечать явно.

## Приёмка

- JSON содержит планы, модели, лимиты с единицами, окна сброса, цены и источник с датой проверки у каждого факта.
- Неизвестные значения обозначены явно с причиной.
- Отчёт называет просмотренные источники, найденные и проверенные материалы, ошибки доступа и необработанную часть.
- Условие завершения партии: 5+ подписок либо исчерпание области поиска.
