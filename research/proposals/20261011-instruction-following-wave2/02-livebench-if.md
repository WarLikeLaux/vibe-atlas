## Тест и результаты

- Название и версия: LiveBench-2026-06-25, категория IF. Новую версию нельзя смешивать с историческими релизами.
- Назначение и тип задач: ограничения в paraphrase, simplify, story_generation и summarize, состав подтверждён JSON релиза.
- Метрика, единицы и направление: баллы подзадач на шкале 0–100, выше лучше. Среднее IF ниже является расчётом Vibe Atlas по четырём исходным столбцам, округлённым до одного знака для чтения.

- Соответствие каталогу: названия в CSV и отображаемые названия в JS сайта подтверждают версии. API snapshot каждого запуска не раскрыт. `muse-spark-1.3-xhigh` относится к обычной 1.3, Contributor не подтверждён. `minimax-m3` не заменяет M3.1 Flash Preview.
- Агент, версия, effort и режим: effort отражён в суффиксах `max`, `xhigh`, `high`. Для GLM и MiniMax effort неизвестен, суффикса нет. Версия harness, temperature, seed и фактические token budgets строк не раскрыты CSV.
