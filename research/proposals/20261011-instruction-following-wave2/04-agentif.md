## Тест и результаты

- Название и версия: AgentIF, October 2026 setting. Исправлены checker, изменены judge, decoding и число запусков. Semver набора не опубликован.
- Назначение и тип задач: длинные системные инструкции из агентских сценариев, условия и спецификации инструментов. Оценивается следование в ответе, результат не выдаётся за успешность реального выполнения инструментов.
- Метрика, единицы и направление: CSR (доля выполненных отдельных ограничений) и ISR (доля инструкций, где выполнены все ограничения), проценты, выше лучше.
- Исходное название модели: `[T]GLM-5.3-Flash` и `[T]GLM-5.3`.
- Соответствие каталогу: configs указывают API IDs `glm-5.3-flash` и `glm-5.3`, thinking. Два варианта сохранены отдельно.
- Агент, версия, effort и режим: config-driven `run.sh`, backend API, effort `max`, temperature 1.0, top_p 0.95, max_tokens 32768. Judge `gpt-5.6-luna`, effort medium, temperature 1, бюджет 8192. Версия API snapshot не опубликована.
- Результат: **GLM-5.3-Flash CSR 64.43 ± 0.19, ISR 24.89 ± 0.37**. **GLM-5.3 CSR 64.21 ± 0.26, ISR 27.06 ± 1.04**. Также сохранены все шесть опубликованных подметрик каждой строки.
- Число задач, попытки, бюджеты и среда: 707 инструкций, три независимых samples по модели и режиму. Неудачный или пустой ответ даёт fail всех ограничений. Для GLM опубликованы API-конфиги, локальный vLLM не приписан этим строкам.
- Доверительный интервал: не опубликован. Знак ± обозначает sample standard deviation трёх запусков, а не CI.
- Машинный набор: [agentif-results.json](agentif-results.json), две строки текущей таблицы и раскрытые параметры config.
- Способ извлечения и снимок: HTML current table, точные имена и configs. Поле rank в исходном HTML пустое, место не выдумывалось. Хеши источников в реестре, адаптер не создавался.
- Охват: две актуальные GLM-конфигурации. Остальные модели текущей таблицы вне выбранных версий, legacy-результаты не импортированы.

Состояния ниже относятся к указанному замеру и версии. Дата разбора: `2026-10-11T20:40:50+00:00`. «Вывод исследователя» отделяет интерпретацию от сообщения источника.

- Независимость: `unknown`. Исполнители названы как команда benchmark, коммерческие связи и актуальное финансирование не выяснены. Не назначать независимость по академическому домену.
- Утечка и обучение на тесте: `unknown`. Набор открыт, для актуальных GLM пересечения с обучением не проверены.
- Насыщение: `not-reviewed`. Диапазон двух моделей не позволяет оценить весь каталог, оценка других групп не выполнялась.
- Воспроизводимость: `supported` для публичных протокола, данных и configs. Независимый повтор `unknown`. [Текущий README](https://github.com/THU-KEG/AgentIF) указывает CC BY 4.0 для данных и Apache-2.0 для кода. Исторические лицензионные указания статьи не переносятся на текущие файлы.
- Сопоставимость: `supported` для запрета смешивания legacy/current, который прямо указан [авторами](https://agentif.github.io/). Для двух GLM параметры одинаковы, влияние model judge остаётся непроверенным. Точное разбиение code/LLM checks и validator reliability требуют отдельного аудита.
