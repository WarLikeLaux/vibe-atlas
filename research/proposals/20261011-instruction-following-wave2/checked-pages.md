## Ошибки доступа и ограничения чтения

- HTML-страница livebench.ai отдаёт только JavaScript shell. Поиск показывает индексированную таблицу, но числа в передаче проверены по прямым CSV и составу категории, а не по поисковому сниппету. Среднее IF явно помечено расчётом Vibe Atlas.
- Web reader не открыл `https://huggingface.co/datasets/developer0hye/HanIFEval/blob/v1.1/README.md`. Прямое чтение `resolve/v1.1/README.md` успешно, dataset и версия проверены. Отказ инструмента не трактуется как отсутствие данных.
- Предположенные пути AgentIF `configs/GLM-5.3.yaml` и `configs/GLM-5.3-Flash.yaml` вернули 404. После чтения дерева репозитория найдены и прочитаны реальные lowercase пути. Ошибка регистра устранена, configs не объявлены отсутствующими.
- При навигации одна ошибочная поисковая ссылка arXiv вернула 404. Она не использована как источник. Настоящий оригинал IFEval 2311.07911 прочитан.
- GitHub web-страницы некоторых источников частично отдавали служебный интерфейс. Числовые значения и настройки сверены через публичные raw-файлы, успешные URL находятся в реестре.

Все основные источники шести карточек доступны. Неполнота полного импорта, нераскрытые настройки и нерешённые методологические вопросы перечислены отдельно в карточках и [списке вопросов](open-questions.md).
