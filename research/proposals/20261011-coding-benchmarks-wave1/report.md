# Передача исследования coding benchmarks

Конечная партия выполнена 11 октября 2026, Asia/Omsk: **8 семейств, 30 первичных материалов, 9 карточек**. Лимит партии исчерпан, дальнейшие страницы не открывались. Результат является исследовательской передачей для отдельной сверки и интеграции.

В [results.json](results.json) сохранены 26 записей запусков/конфигураций, 4 конфигурации с временными окнами, 442 числовые оконно-языковые ячейки, 530 ячеек `needs-context` и 400 результатов отдельных задач. Найдены 12 безусловных соответствий моделей редакционного каталога и одно условное для Composer 2.5: исторические окна Cursor требуют проверки версии. Это счёт записей передачи, а не число независимых экспериментов. Точный охват и все отсутствующие соответствия перечислены в [coverage.json](coverage.json), исходный редакционный список в [scope.json](scope.json).

Исследование началось 11 октября по местному времени. Метки получения и проверки записаны в UTC: 10 октября вечером UTC соответствует 11 октября в Asia/Omsk. Дата публикации источника хранится отдельно от даты проверки и от `createdAt` строки. Если публикация неизвестна, значение осталось `null`.

## Материалы передачи

- [Карточки](cards/swe-bench-family.md) перечислены в таблице ниже. Все используют разделы шаблона `docs/templates/benchmark-finding.md`.
- [Паспорта методологии](methodology.md) разделяют версии, поднаборы и протоколы и содержат конкретные основания разбора доверия.
- [results.json](results.json) содержит соответствия каталогу, исходные названия, конфигурации, метрики, единицы, неизвестные значения и ссылки на числовые снимки.
- [Реестр оригиналов](evidence/sources.json) содержит URL, время, HTTP-статус и SHA-256 полученного ответа для каждого из 30 материалов.
- [Реестр артефактов](evidence/artifacts.json) содержит относительные пути и SHA-256 файлов передачи. Сумма ответа оригинала и сумма извлечённого JSON относятся к разным объектам.
- [validation.json](validation.json) фиксирует выполненную проверку передачи.

Полные ответы HTML и тексты статей не архивировались. Сохранены извлечённые опубликованные числовые данные и доступные поля этих данных. `source-verified` означает сверку с прочитанным оригиналом. Это не заключение о независимости, отсутствии утечки или готовности к публикации.

## Отсутствия, неполнота и следующий шаг

Для пяти позиций основного набора точные результаты **не найдены в проверенных 30 материалах**: GPT-6.1 Luna, GLM-5.3-Flash, Grok 4.7, MiniMax-M3.1-Flash-Preview и Muse Spark 1.3 Contributor. Это граница исследования, не утверждение об отсутствии результатов в интернете или об отсутствии самой модели. Для Composer 2.5 есть поздняя конфигурация в Insights, но точная модель каждой исторической ячейки не установлена. Для остальных моделей каталога полный список отсутствующих соответствий сохранён в `catalogueModelsWithoutExactMappingInCheckedScope` в [coverage.json](coverage.json).

Официальность и актуальность всех вендорских линеек заново не проверялись. [scope.json](scope.json) фиксирует редакционный контекст, а не справочник подтверждённых API IDs. Не подставлены соседние поколения, модели без Preview или Muse без Contributor. DeepSeek V4 Pro без 0813 в SWE-rebench оставлен исходным именем без точного соответствия.

Известная неполнота партии:

1. LiveCodeBench: прочитан generation endpoint, не извлечены self-repair, execution, test output prediction и GSO. Следующая отдельная партия должна определить актуальную таблицу и release каждого сценария.
2. Aider: Polyglot извлечён полностью из просмотренной страницы. Старые code editing/refactoring таблицы не открывались. Следующий шаг: проверить их страницы, только затем утверждать отсутствие актуальных версий в этих сценариях.
3. SWE-rebench V2: [коллекция](https://huggingface.co/collections/nebius/swe-rebench-v2) прочитана как указатель, проверено 11 октября 2026. Сам новый набор и новая статья V2 не разобраны. Редакция v2 статьи с другим названием не стала версией leaderboard.
4. BigCodeBench: Full/Hard endpoints сохранены, отдельный HF Space не прочитан. EvalPlus: отдельный EvalPerf не разобран. Эти направления требуют отдельного лимита страниц.
5. Траектории отдельных агентов, версии harness, условия каждой приватной задачи и повтор запусков не проверены. Перед интеграцией нужна сверка конкретного протокола, а не наследование настроек из общего README.
6. Пересечение обучающих корпусов и финансирование сверх явно раскрытого источниками не исследовались. Паспорта сохраняют `unknown` и `not-reviewed` вместо общего обещания чистоты и независимости.

Поздняя дополнительная сверка уже учтённого оригинала SWE-rebench сохранена в [mapping context](evidence/swe-rebench-mapping-context.json) с отдельным временем и суммой ответа. Число уникальных оригиналов осталось 30.

Мнения и голосования в этой партии не собирались. Числовые тесты не смешаны с отзывами. Поисковые сниппеты и вторичные пересказы не стали карточками `source-verified`. Собственная оценка стоимости по токенам и собственный общий рейтинг не рассчитывались.

## Дубликаты и расхождения

Локально прочитаны `data/sources.json` и существующие импорты для AA, Cursor и Terminal-Bench. Эти источники повторно не импортировались. В Cursor уже есть вендорский SWE-bench Multilingual. Официальный SWE-bench leaderboard является другим представлением и источником запусков. В полученном официальном снимке нет точных текущих моделей для повторного нормализованного импорта. Composer 2.5 в SWE-rebench относится к другому тесту, а не повтору CursorBench. Существующие общие файлы не редактировались.

Повторы внутри новых источников:

- SWE-Bench Pro: Full headline, public/private график и public график статьи могут представлять один результат с разной точностью. Они сохранены исходными данными, не сложены как независимые замеры. Full и HARD являются разными поднаборами. Headline и отдельное исследование harness получили разные protocol IDs.
- ProgramBench: основная таблица, Extended, plot и run pages являются связанными представлениями. Сохранены все числа, отличающаяся точность и расхождения таблиц. Их не считают несколькими экспериментами.
- SWE-rebench: пересекающиеся даты, All и отдельные языки могут использовать одни задачи. Количество окон не даёт дополнительных независимых подтверждений.
- EvalPlus: исходные и Plus tests оценивают связанные генерации. Расхождение 399/378 задач MBPP между таблицей и README оставлено `disputed` в паспорте.

Оригиналы для каждого пункта и дата 11 октября 2026 находятся в соответствующей [карточке](cards/swe-bench-pro-v2.md) и [паспорте](methodology.md). Точную идентичность всех исторических чужих запусков с существующими импортами доказать по просмотренным метаданным нельзя, поэтому автоматическое удаление дублей не выполнялось.

## Доступ и проверка

Публичный доступ позволил получить все 30 перечисленных оригиналов, HTTP 200. Чтение SWE-rebench и generation JSON LiveCodeBench через браузерный инструмент встретило лимит размера ответа, чтение Scale V2 blog этим инструментом было недоступно. Прямой публичный HTTP вернул полные ответы. Числа извлечены из JSON, HTML tables и встроенных React Flight данных, а не из поисковых сниппетов. Динамический экран загрузки сам по себе не считался результатом. Приватные учётные данные не использовались.

Выполненная проверка [validation.json](validation.json): все JSON разбираются, числа конечны, IDs уникальны, модели входят в snapshot охвата. Разрешены 866 обращений к указателям числовых снимков. Все 26 нормализованных конфигураций, 972 оконные ячейки и 400 per-instance строк сверены с сохранёнными исходными значениями. Проверены разделы 9 карточек, ссылки, даты и суммы исходных ответов. Проверка передачи не является повтором бенчмарков.

Запись выполнялась только в папку этого задания. Код, общие данные, зависимости и чужие исследования не изменялись. Адаптер не разрабатывался, агенты не запускались, commit, push и публикация не выполнялись. `npm run check` не запускался: эта партия не меняет исполняемый код или импортируемые данные и не публикуется. Интеграционная проверка и публикация выполняются отдельно после сверки.
