- Название и версия: Опубликованные time-window оценки, явная версия общего leaderboard не указана. Коллекция нового набора V2 не присвоена старым строкам.
- Назначение: Исправление задач из GitHub PR с фильтром даты и языка.
- Метрика и единицы: Resolved Rate и Pass@5 (%), USD/problem, tokens/problem, cached %. sem сохраняется отдельно.
- Исходные названия и соответствие: Точные текущие соответствия: MiniMax M3, Gemini 3.1 Pro Preview, Qwen3-Coder-Next. Поздние Insights раскрывают Composer 2.5, исторические Composer 2. Соответствие каждой Cursor-ячейки Composer 2.5 остаётся кандидатом `needs-context`. DeepSeek-V4 Pro без 0813 не подменяет каталог.
- Агент, версия, effort и режим: sourceAgentMode tools, modelId и release поля сохранены. Для модельных записей точный harness неизвестен, effort всех четырёх неизвестен.
- Результат: Окно 2026-05-15 … 2026-07-01: Cursor 51.7% и MiniMax M3 47.2% в отображаемой точности. В JSON лежат исходные дробные значения и все остальные окна.
- Задачи, попытки, бюджет и среда: Default view показывает 111 задач / 65 репозиториев. Для отдельных окон размеры не установлены, boundaries требуют сверки frontend.
- Доверительный интервал: Вместо CI опубликовано поле sem. Уровень интервала не выдуман.
- Машинный набор: results.json#windowedResults, evidence/swe-rebench-datasets.json (пути от корня папки передачи).
- Способ извлечения: React Flight: извлечены problems, items/rangeStats и две серии графика. Все поля оригинала сохранены.
- SHA-256 ответа оригинала: `fbb1b659562843da266aa20ec2295253d727ccd9b9469c78ab32df6fad1fffed`. Контрольные суммы файлов передачи: [artifacts.json](../evidence/artifacts.json).
- Инструмент: разовый разбор публичного ответа HTTP в ходе исследования. Адаптер сайта не разрабатывался.
- Охват: 117 source items и 970 задач сохранены. Для трёх точных моделей и условного соответствия Cursor переданы все 972 source window-language ячейки: 442 числовые и 530 needs-context.

- Сверка по оригиналу: исполнена для описанного извлечения и условий, `2026-10-10T18:48:05.298665+00:00`.
