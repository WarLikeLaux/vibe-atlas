## Тест и результаты

- Название и версия: Aider Polyglot, 225 упражнений, номер ревизии benchmark dataset не раскрыт.
- Назначение: Редактирование кода по заданию с автоматической обратной связью и проверками.
- Метрика и единицы: Percent correct, Correct edit format, Pass rate 1/2 в процентах. Выше лучше.
- Исходные названия и соответствие: 69 конфигураций, все строки сохранены. Точных версий текущего охвата не найдено. gpt-5 (high/medium/low/minimal) не подменяет GPT-6.1 Sol.
- Агент, версия, effort и режим: Команды, edit format, reasoning_effort, thinking_tokens, aider versions и commit hash сохранены в raw detail строках.
- Результат: В текущем охвате отсутствует в обработанной таблице, старые баллы не перенесены.
- Задачи, попытки, бюджет и среда: 225 Exercism задач, шесть языков. В деталях есть первая и вторая фазы прохождения.
- Доверительный интервал: В таблице не обнаружен, не рассчитан.
- Машинный набор: evidence/aider-tables.json (пути от корня папки передачи).
- Способ извлечения: Прочитаны обычные и detail строки исходного HTML table. Данные не ограничены лучшим effort.
- SHA-256 ответа оригинала: `cea6cab3ac65e4d41cce072fcac5540497d757b3a6f72d997b7c3607b44c470e`. Контрольные суммы файлов передачи: [artifacts.json](../evidence/artifacts.json).
- Инструмент: разовый разбор публичного ответа HTTP в ходе исследования. Адаптер сайта не разрабатывался.
- Охват: Весь текущий Polyglot leaderboard, 69 пар display/detail. Старые code editing и refactoring таблицы не просмотрены.

## Проверка и передача

- Сверка по оригиналу: исполнена для описанного извлечения и условий, `2026-10-10T18:45:57.901730+00:00`.
- Проверяющая роль: исследователь бенчмарков Vibe Atlas. Независимой повторной проверки другим исполнителем не было.
- Дубликаты: Индекс AA и другой агент не считаются повторным замером Aider. Дубликаты одинаковых исторических запусков вне Polyglot не проверялись.
