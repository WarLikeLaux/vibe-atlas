## Тест и результаты

- Название и версия: ProgramBench, таблица 200 задач. Отдельный номер ревизии набора не указан.
- Назначение: Реализация программы с нуля по binary и документации, проверка поведения программными tests.
- Метрика и единицы: Resolved и Almost Resolved в процентах, plot Behavioral Test Pass Rate в исходной дробной шкале. Выше лучше.
- Исходные названия и соответствие: Muse Spark 1.3 (max) и Muse Spark 1.3 (xhigh), связь с обычной моделью каталога. Contributor не указан и не подставлен.
- Агент, версия, effort и режим: mini-SWE-agent, effort max/xhigh. Версия и точные бюджеты отдельных запусков неизвестны.
- Результат: max: Resolved 2.5%, Almost 25.0%, plot score 0.708. xhigh: 1.0%, 16.5%, plot score 0.6859999999999999. Значения разных метрик сохранены отдельно.
- Задачи, попытки, бюджет и среда: 200 per-instance строк на конфигурацию. xhigh указывает 199 solutions и содержит n/a. Denominator общей метрики не уточнён.
- Доверительный интервал: Не опубликован в просмотренных таблицах, не рассчитан.
- Машинный набор: results.json, evidence/programbench-results.json, evidence/programbench-muse-max-tables.json, evidence/programbench-muse-xhigh-tables.json (пути от корня папки передачи).
- Способ извлечения: HTML table, plot array results и run pages оригинального сайта. Per-instance результаты обеих конфигураций сохранены полностью.
- SHA-256 ответа оригинала: `0eff9a5d625831635c1a23a24312b02a9d82adc0033c3b580dfb70f75ddcd432`. Контрольные суммы файлов передачи: [artifacts.json](../evidence/artifacts.json).
- Инструмент: разовый разбор публичного ответа HTTP в ходе исследования. Адаптер сайта не разрабатывался.
- Охват: Все 25 plot rows и 26 основного HTML table (включая скрытую строку) сохранены. 24 extended rows. В results.json две текущие конфигурации и 400 их task rows.
